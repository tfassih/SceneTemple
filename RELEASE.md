SceneTemple’s first desktop release includes 14 writing templates, project files with reusable template and component libraries, a navigable outline, focus mode, offline English proofreading, and formatted PDF and editable DOCX export.

| Platform | File |
| --- | --- |
| Windows 11 x64 | Windows x64 Setup EXE |
| macOS Monterey or later on Intel | macOS Intel DMG |
| macOS Monterey or later on Apple silicon | macOS Apple Silicon DMG |
| Ubuntu 24.04 x86-64 | Ubuntu amd64 DEB |
| Desktop browser | Portable ZIP (extract and open index.html) |

Windows has no publisher signature. The Mac applications are ad-hoc signed and have no Apple notarization. SHA256SUMS.txt lists the release hashes. Native packages bundle their writing runtime. Ubuntu also uses standard system desktop libraries.
